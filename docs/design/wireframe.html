Daily life side quests

A UI-only POC prototype for students to try daily and long-term quests, build routines, reflect briefly, and keep shared streaks with friends.

Flow notes

Auth -> onboarding -> home
Home -> quest detail -> progress or complete
Completed quest -> quest reflection
Profile -> friends, feedback, and suggestions
  • Quest progress can span days through long-term quest states.
  • Shared streaks now cover invites, connections, and liked quests.
  • Profile stores theme choice and links to feedback/suggestions.
